# Public Evidence

This directory contains reviewed, lightweight summaries only. Full results,
raw ECG, per-record predictions, window caches, and private model artifacts are
not distributed in this repository.

The summaries are traceable to the local artifact paths recorded in `AGENTS.md`.
`software_freeze_manifest.json` records the frozen model hashes, and
`service_loop_summary.json` records source hashes for the later software-loop
and exploratory replay evidence.
